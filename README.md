# OneERP – FICO Module Development

## Project Overview
This project focuses on developing an ERP Finance and Controlling (FICO) module.

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: MySQL
- ORM: SQLAlchemy
- API Testing: Swagger UI

## Project Structure
- Backend – API and business logic
- Frontend – User interface
- database – Database-related files

## Setup Instructions
1. Clone the repository.
2. Install Python dependencies using `pip install -r requirements.txt` (if the requirements file is provided).
3. Create your local `.env` file using `.env.example`.
4. Configure your MySQL database.
5. Start the backend using `python -m uvicorn main:app --reload`.

## Security
Never upload `.env` or authentication secrets to GitHub.
